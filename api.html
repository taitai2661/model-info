Model Info APIModel Info API

Model Info は検証済みの事実を静的 JSON として配信します。サーバーサイド API はなく、すべてのエンドポイントはコミット済みファイルです。ここでは取得方法とデータの形を説明します。 Model Info serves verified facts as static JSON. There is no server-side API — every endpoint is a committed file. This page documents how to fetch the data and what shape it takes.

Base URL

同一のファイルを2つの静的ホスト(Cloudflare Pages と GitHub Pages)で配信しています。どちらの配信ルートからも同じ内容が取得できます。サイト自身と同じく、ローカルにクローンしてもそのまま動きます。

Identical files are served by two static hosts (Cloudflare Pages and GitHub Pages); either deployment root returns the same content. The same paths also work from a local clone.

https://model-info.ta26.top/v1/
https://taitai2661.github.io/model-info/v1/

論理エンドポイントごとに ….json と …/index.json の2形式があります（静的ホスティングは拡張子なし URL を配信できないため）。どちらも同じ内容です。 Each logical endpoint has two forms: ….json and …/index.json (static hosting cannot serve extensionless paths). Both return the same content.

リクエスト例Examples

認証は不要です。公開ファイルをそのまま取得できます。

No authentication is required — fetch the public files directly.

curl

curl https://model-info.ta26.top/v1/models.json
curl https://model-info.ta26.top/v1/models/gpt-5.json
curl https://model-info.ta26.top/v1/providers/openrouter/models.json

JavaScript (fetch)

const base = "https://model-info.ta26.top/v1";

const models = await (await fetch(`${base}/models.json`)).json();
const detail = await (await fetch(`${base}/models/gpt-5.json`)).json();

// detail.model  -> specs (context, capabilities, pricing, ...)
// detail.providers -> per-provider model_id, base_url, auth, pricing

上書き規則 (Model × Provider)Override semantics (Model × Provider)

関係エントリ内の任意キーは3値で表現します。

Optional keys inside a relationship entry use a three-state convention.

形式Form 意味Meaning
key omittedモデル定義の値を継承Inherit the value from the model document
nullこのプロバイダーでは不明Unknown at this provider
valueモデル側の値を上書きOverride the model-level value

ネストしたオブジェクト（pricing / context / modalities / capabilities / reasoning / service_tier / api_variant / api_capabilities）は丸ごと置き換わります。置換後に省略されたフィールドは「不明」であり、継承ではありません。 Nested objects (pricing, context, modalities, capabilities, reasoning, service_tier, api_variant, api_capabilities) replace the model-level object wholesale. Fields omitted inside the replacement are unknown, not inherited.

データ規則と enumData rules & enums

  • 推測しない。Never guess. 不明なコンテキスト長・料金・機能は null（またはキー省略）。0 が意味を持つのは明示的な無料料金のみです。 Unknown context windows, prices or capabilities are null (or omitted). 0 is meaningful only for an explicitly free price.
  • 出典を必ず記録。Every fact has sources. sources[] に type・url・retrieved_at を保持します。 sources[] records type, url and retrieved_at.
  • 秘密情報は保存しない。No secrets, ever. API キーは一切保存しません。検証が資格情報らしき文字列を走査します。 API keys are never stored. Validation scans all data for credential-like strings.
フィールドField 値Values
statusactive | preview | experimental | deprecated | retired | unknown
api_styleopenai_compatible | anthropic | google_generative_ai | custom
authentication.typebearer | api_key | oauth | none | custom
modalitiestext | image | audio | video | file

日時は YYYY-MM-DD。料金は currency + unit（既定 1M_tokens）単位です。 Dates are YYYY-MM-DD. Prices are per unit (default 1M_tokens) in currency.

MIX-agent

セルフホストのAIワークスペース。Model Info が扱う Provider と Capability（Context Window / Reasoning / Vision / Tool Calling）を自動検出し、自分のサーバーで会話や作業を行えます。AI モデルは付属しないため、クラウド API キーまたは Ollama などを自分で接続します。 A self-hosted AI workspace. It auto-detects the providers and capabilities Model Info describes (context window, reasoning, vision, tool calling) and runs entirely on your own server. AI models are not bundled — connect a cloud API key or a local runtime such as Ollama.
